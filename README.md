# Python Learning Journey

This repository contains simple games, scripts, and programs I developed while learning Python. The goal of this project is to practice core Python concepts, data structures, and file operations.

## 🚀 Projects Included

* **Guess the Number Game:** A console-based game using the `random` module, loops, and conditional statements to guess a randomly generated number within a chosen interval.
* **Server Log Analyzer:** A script that reads a log file, processes text lines using string splitting (`split()`), and counts log frequencies (INFO, ERROR, WARNING) using Python dictionaries.
* **Student GPA Calculator:** A program that performs file I/O operations to parse student grades, stores data dynamically in nested structures (dictionary with lists), and calculates average scores.
* **ATM Simulator:** A console-based banking application featuring a continuous menu loop (`while`), allowing users to check balance, deposit, and withdraw money with basic conditional logic.

## 🛠️ Core Concepts Practiced

* Variable scopes and `global` keyword
* File handling (`with open()` and character encoding)
* Data structures (Lists, Dictionaries)
* String manipulation and formatting (f-strings)
* Exception handling (`try-except`)
